# AI Fitness Coach

A Java console application that helps users with:

• User Registration
• BMI Calculator
• BMR Calculator
• TDEE Calculator
• Diet Recommendations
• Workout Recommendations
• Workout Schedule
• Save & View Reports
• Input Validation
• File Handling

## Technologies Used
- Java
- OOP
- File Handling
- Git
